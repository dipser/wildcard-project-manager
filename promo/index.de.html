VS Code Extension

Ein Häkchen statt vierzig Favoriten.

Wildcard Project Manager verwaltet Projekte über Pfad-Muster statt über Einzeleinträge. Ein Glob-Pfad wie /var/www/* reicht – jeder Unterordner wird automatisch zu einem Projekt, lokal wie per SSH.

Einzeln gepflegte Favoriten

Jeder Server-Ordner wird einzeln per Rechtsklick zu den Favoriten hinzugefügt. Legt der Kollege einen neuen Ordner unter /var/www/ an, taucht er erst auf, wenn ihn jemand manuell einträgt.

Wildcard Project Manager

Ein Pfad-Muster pro Server reicht. Neue Ordner unter /var/www/* erscheinen beim nächsten Öffnen der Seitenleiste automatisch – ohne dass irgendjemand die Konfiguration anfassen muss.

So funktioniert's

Drei Felder pro Gruppe: ein Name, eine Liste von Pfaden, fertig.

  1. Gruppe anlegen

    Ein Eintrag in der Konfiguration, z. B. „Server 1“ – wird als Kategorie in der Seitenleiste angezeigt.

  2. Glob-Pfad eintragen

    Ein Pfad wie vscode-remote://ssh-remote+myremoteserver/var/www/* wird als Verzeichnis gescannt.

  3. Ordner erscheinen automatisch

    Jeder gefundene Unterordner wird zum klickbaren Projekt. hidden blendet einzelne Namen aus.

Die Konfiguration

Eine editierbare JSON-Datei, ein Array von Gruppen. Kein UI-Formular, kein Settings-Sync-Rauschen.

1[2  {3    "name": "Server 1",4    "paths": ["vscode-remote://ssh-remote+myremoteserver/var/www/*"],5    "hidden": [],6    "order": 17  },8  {9    "name": "Lokal",10    "paths": ["file:///home/user/projects/*"],11    "hidden": ["node_modules"],12    "order": 2,13    "collapsed": true,14    "settings": {15      "shop": { "icon-image": "rocket", "icon-color": "charts.red" }16    }17  }18]
name
Anzeigename der Gruppe (Kategorie) in der Seitenleiste.
paths
Liste von URIs. Endet ein Pfad auf *, werden alle passenden Unterordner als Projekte gelistet. Ohne Wildcard zählt der Pfad selbst als ein Projekt.
hidden
Ordnernamen (auch mit */?), die aus dem Scan-Ergebnis ausgeschlossen werden.
order
Sortierreihenfolge der Gruppen, aufsteigend. Wird beim Umsortieren per Drag & Drop neu geschrieben.
collapsed
Gruppe startet zugeklappt. Bei aktiver Suche klappt sie trotzdem auf, damit die Treffer sichtbar sind.
settings
Icon und Farbe je Projekt: icon-image ist eine Codicon-ID, icon-color eine Theme-Farb-Id. Wird per Rechtsklick gesetzt, nicht von Hand.

Installation

Verfügbar im Open VSX Marketplace – in VSCodium, Cursor und Windsurf direkt installierbar. Für VS Code liegt die fertige .vsix im Ordner releases/ – herunterladen, installieren, Fenster neu laden.

$ code --install-extension wildcard-project-manager-1.0.2.vsix
→ Extension installiert · danach „Developer: Reload Window“

Oder selbst bauen:

$ npm install
$ npm run compile
$ npm run package
→ releases/wildcard-project-manager-1.0.2.vsix
