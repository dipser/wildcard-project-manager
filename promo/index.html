One checkmark instead of forty favorites.

Wildcard Project Manager manages projects through path patterns instead of individual entries. A glob path like /var/www/* is all it takes – every subdirectory becomes a project automatically, locally and over SSH.

Maintaining favorites does not scale

Favorites maintained one by one

Every server directory is added to the favorites one at a time by right-click. When a colleague creates a new directory under /var/www/, it only shows up once somebody enters it by hand.

Wildcard Project Manager

One path pattern per server is enough. New directories under /var/www/* appear automatically the next time the sidebar opens – without anyone touching the configuration.

How it works

Three fields per group: a name, a list of paths, done.

  1. Create a group

    One entry in the configuration, e.g. “Server 1” – shown as a category in the sidebar.

  2. Add a glob path

    A path like vscode-remote://ssh-remote+myremoteserver/var/www/* is scanned as a directory.

  3. Directories appear automatically

    Every subdirectory found becomes a clickable project. hidden excludes individual names.

The configuration

One editable JSON file, an array of groups. No UI form, no settings-sync noise.

1[2  {3    "name": "Server 1",4    "paths": ["vscode-remote://ssh-remote+myremoteserver/var/www/*"],5    "hidden": [],6    "order": 17  },8  {9    "name": "Local",10    "paths": ["file:///home/user/projects/*"],11    "hidden": ["node_modules"],12    "order": 2,13    "collapsed": true,14    "settings": {15      "shop": { "icon-image": "rocket", "icon-color": "charts.red" }16    }17  }18]
name
Display name of the group (category) in the sidebar.
paths
List of URIs. If a path ends in *, every matching subdirectory is listed as a project. Without a wildcard the path itself counts as one project.
hidden
Directory names (*/? allowed) excluded from the scan result.
order
Sort order of the groups, ascending. Rewritten when reordering by drag & drop.
collapsed
Group starts collapsed. With an active search it expands anyway so the matches stay visible.
settings
Icon and color per project: icon-image is a codicon ID, icon-color a theme color ID. Set by right-click, not by hand.

Installation

Available on the Open VSX Marketplace – installable directly in VSCodium, Cursor and Windsurf. For VS Code the built .vsix lives in releases/ – download, install, reload the window.

$ code --install-extension wildcard-project-manager-1.0.2.vsix
→ Extension installed · then “Developer: Reload Window”

Or build it yourself:

$ npm install
$ npm run compile
$ npm run package
→ releases/wildcard-project-manager-1.0.2.vsix
